# Cormorant Garamond

Fuente variable tomada de https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Licencia: SIL Open Font License 1.1 — permite uso, modificación y redistribución,
incluso comercial, mientras se conserve el aviso de licencia.

Se versiona en el repositorio a propósito: los PDF se generan en el servidor y
tienen que salir idénticos siempre, sin depender de que una fuente esté instalada
en la máquina donde corra el proceso.

Solo existe como fuente variable —no hay instancias estáticas publicadas—, así que
se usa en su peso por defecto para el membrete. Los datos van en una sans, que
además lee mejor las cifras.
